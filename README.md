# cody_mission2

## 1. 프로젝트 개요
Python 기본 문법과 객체지향 프로그래밍을 활용하여 터미널에서 실행하는 퀴즈 게임을 개발합니다. Git과 GitHub를 사용하여 기능별 변경 이력을 기록하고 협업합니다.

## 2. 퀴즈 주제 및 선정 이유
퀴즈 주제: 스포츠
선정 이유: 작성자가 스포츠를 좋아하기때문
문항 수: 5문항 이상 (각 문항은 문제, 선택지 4개, 정답 포함)

## 3. 주요 기능
1. **퀴즈 풀기:** 저장된 문제를 출제하고 정답 여부 및 최종 점수를 표시합니다.
2. **퀴즈 추가:** 문제, 선택지 4개, 정답 번호를 입력하여 새 퀴즈를 등록합니다.
3. **퀴즈 목록:** 등록된 퀴즈 목록을 확인합니다.
4. **점수 확인:** 최고 점수를 조회하고 퀴즈 결과에 따라 갱신합니다.
5. **데이터 저장/불러오기:** 프로그램 종료 후에도 퀴즈와 최고 점수를 유지합니다.
6. **입력 오류 처리:** 잘못된 메뉴 번호, 빈 입력, 숫자 변환 오류, 파일 누락·손상 등을 처리합니다.

## 4. 기술 스택
- Python 3
- JSON (`quiz_data.json` 데이터 저장)
- Git / GitHub (버전 관리 및 협업)

## 5. 파일 구조
```text
cody_mission2/
├── README.md          # 프로젝트 소개 및 사용 안내
├── .gitignore         # Git 추적 제외 규칙
├── maincode.py        # 모든 클래스와 함수가 포함된 스크립트 
└── quiz_data.json         # 퀴즈 목록 및 최고 점수 (실행 중 생성/관리)
```

## 6. 실행 방법
1. Python 3을 설치합니다.
2. vscode 편집기를 열고 프로젝트 폴더에서 터미널을 실행합니다.
3. 다음 명령어로 프로그램을 실행합니다.
```bash
python3 maincode.py
```

프로그램 실행 시 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 점수 확인, 종료를 선택합니다.

## 7. 데이터 파일 설명 (`quiz_data.json`)
프로젝트 루트의 `quiz_data.json`에 퀴즈 목록과 최고 점수를 UTF-8 형식으로 저장합니다.

```json
{
  "high_score": 0,
  "quizzes": [
    {
      "question": "Python에서 리스트를 나타내는 기호는?",
      "options": ["()", "[]", "{}", "<>"],
      "answer": 2
    }
  ],
}
```
- `high_score`: 최고 점수
- `quizzes`: 등록된 퀴즈 목록
- `question`: 문제
- `options`: 4개의 선택지
- `answer`: 정답 번호 (1~4)


## 8. 과제 목표
(1) Python의 기초  
`변수가 무엇이고, 왜 사용하는지 설명할 수 있다.` : 프로그램 언어에서 변수란 특정한 값을 저장하는 공간으로 이해할 수 있으며, 모든 코딩은 이 변수를 기반으로 만들어진다.  
`int, str, bool, list, dict의 차이를 설명할 수 있다.` : int는 정수형, str은 문자형, bool은 참/거짓 변수를 만들 때 사용된다. list는 여러개의 변수를 담을 수 있는 그릇이고, dict형 변수는 list와 비슷하지만 key와 value의 쌍으로 값을 저장한다.  
`if/elif/else로 조건에 따라 다른 동작을 수행할 수 있다.` : if는 조건문이고 조건이 참 일때 아래 구문을 수행한다. elif는 다른 조건에 해당하는지 판별하며, else는 모든 조건이 다 아닐 때 다음 구문을 실행하기 위한 명령어다.  
`for와 while의 차이를 설명하고 적절히 선택할 수 있다.` : for, while문은 둘다 반복적인 작업을 할 때 사용된다. for문은 사용자가 미리 정한 경우의 수만큼 반복하며, while은 결과가 참인 경우에만 반복한다.  
`함수를 정의하고, 매개변수와 반환값을 활용할 수 있다.` : 함수는 "def function_name(input1, input2):" 식으로 정의한다. 정의 시에 입력값을 받을 수 있으며, 출력값으로 내려면 return 명령어를 사용한다.  

(2) 클래스와 객체
`클래스가 무엇이고, 왜 사용하는지 설명할 수 있다.` : 객체를 만들기 위한 틀(설계도)입니다. 객체(Object)는 클래스로부터 만들어진 실제 결과물들입니다.  
`__init__ 메서드와 self의 역할을 설명할 수 있다.` : __init__은 클래스로 인스턴스를 만들 때 자동으로 실행되어 초기값을 설정하는 메서드이고, self는 메서드를 호출한 인스턴스 자기 자신을 가리키는 매개변수입니다.  
`클래스의 속성(attribute)과 메서드(method)를 정의하고 활용할 수 있다.` : 속성과 메서드는 클래스내에서 정의되는 변수 또는 함수로 이해할 수 있다.  

(3) 파일 입출력  
`파일을 열고, 읽고, 쓰는 기본 과정을 설명할 수 있다.` : open 함수를 이용하여 여러확장자의 파일을 열고 읽거나 쓰는게 가능하다.  
`JSON 형식이 무엇이고, 왜 데이터 저장에 사용하는지 설명할 수 있다.` : JSON 파일은 키-값(Key-Value) 쌍으로 이루어진 텍스트 기반의 가벼운 데이터 교환 포맷으로, 시스템 간 데이터 전송이나 설정 저장에 널리 쓰인다.  
`try/except를 사용하여 오류를 처리할 수 있다.` : 오류가 발생할 가능성이 있는 코드는 try 블록 안에 작성한다. 실행 중 오류가 발생하면 해당 지점에서 try 블록의 실행을 중단하고, 발생한 오류에 해당하는 except 블록을 실행한다. 이를 통해 예상되는 오류를 적절히 처리하여 프로그램이 비정상적으로 종료되는 것을 방지할 수 있다. 단, except에서 처리하지 않는 오류가 발생하면 프로그램이 종료될 수 있다.  

(4) Git 기초  
`Git이 무엇이고 왜 필요한지 설명할 수 있다.` : git은 프로그래밍, 문서작성 등의 컴퓨터 작업을 체계적으로 할 수 있게 만들어주는 플랫폼의 역할을 하며, github를 활용하여 다른 사람과의 협업이나 버전 관리를 쉽게 할 수 있다.  
`init, add, commit, push, pull, checkout, clone이 각각 무엇을 하는지 설명할 수 있다.`  
init: 현재 폴더를 Git 저장소로 초기화한다.  
add: 파일의 변경 사항을 스테이징한다.  
commit: 스테이징된 변경 사항을 로컬 저장소의 이력으로 기록한다.  
push: 로컬의 커밋을 GitHub 등의 원격 저장소에 업로드한다.  
pull: 원격 저장소의 변경 사항을 가져와 현재 로컬 브랜치에 반영한다.  
checkout: 브랜치를 이동하거나 특정 버전의 파일을 가져온다.  
clone: 원격 저장소를 로컬에 복제하여 Git 작업을 할 수 있게 한다.  
`브랜치를 생성하고 병합할 수 있다.` : git branch 명령어로 브랜치를 생성할 수 있다. 브랜치는 다른 버전의 작업을 추가하거나 여러 작업이 동시에 진행될 때 사용된다. git merge로 병합할 수 있는데, 이는 다른 브랜치에서 발생한 작업을 다른 브랜치에 합칠 때 사용된다.
